# EthioBricks Website Starter

Open index.html in a browser.

Files:
- index.html — site content
- styles.css — responsive styling
- script.js — demo signup interaction
- lalibela-concept.png — concept artwork

Important:
This is a prototype website, not an ecommerce site. Connect the signup form to a real email/CRM service before collecting customer information.
The product is presented as an original modular building system, not as an official LEGO product.
